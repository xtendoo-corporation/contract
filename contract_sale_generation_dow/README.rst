=======================================
Contract Sale Generation with Day of Week
=======================================

This module extends the contract_sale_generation module to include a `contract.dow`
model that allows setting predefined weekdays for contracts.

Key Features:
-------------
- Added the `contract.dow` model.
- Extended `contract.contract` to include `dow_ids` field.
- Updated views, access rights, and default weekday records.

Installation:
-------------
1. Install this module using the Odoo Apps interface.
2. Configure contracts with weekdays using the model.
